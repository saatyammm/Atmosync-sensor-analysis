Atmosync – Sensor Data Analysis

Project Overview

Atmosync is a sensor data analysis project developed using Python and Streamlit. It focuses on analyzing sensor readings and presenting insights through an interactive dashboard.

Features

- Sensor data generation
- Sensor data analysis using Python
- Data visualization
- Interactive dashboard using Streamlit
- CSV-based sensor data storage

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Git and GitHub

How to Run

1. Clone the repository:

git clone https://github.com/saatyammm/Atmosync-sensor-analysis.git

2. Open the project folder:

cd Atmosync-sensor-analysis

3. Install the required dependencies.

4. Run the Streamlit dashboard:

streamlit run dashboard/app.py
